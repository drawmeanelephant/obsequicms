# P03 work report: pages and structure workspace

Status: complete. Branch `m0-prototype`. Depends on P02.

## What was built

`apps/web/src/features/structure/**` (owned by this packet):

- `StructurePage.tsx` — workspace composition: data loading, view state,
  filters, selection, state banners, and layout.
- `usePageIndex.ts` — loads the page index through the injected client;
  loading / error / ready phases; a failed request renders an explicit
  error banner with a working retry and never an empty success or demo
  fallback.
- `outline.ts` — pure outline construction from explicit `parentId`
  records only. Surfaces satellites whose parent is missing from the
  index and pages trapped in a parentage cycle instead of dropping them.
  `filterOutline` keeps ancestors of matching descendants.
- `filters.ts` — pure combined filters: search (title, source path, or
  entity ID), status (including `unset` as its own value), and tag.
- `dependencies.ts` — pure incoming/outgoing split around a page; source
  endpoints are described as source files and are never resolved into
  pages.
- `OutlineView.tsx` — Astryx `TreeList` of parentage with both root trees
  and every branch pre-expanded; status badges and source paths on rows;
  a separate group for pages without a resolvable parent.
- `InventoryView.tsx` — Astryx `Table` (title, status, tags, source path,
  published URL) with per-row selection buttons; unknown URLs render as
  "Unknown — no release mapping".
- `PageInspector.tsx` — relationship inspector: title, status, tags, and
  a metadata list keeping identity (entity ID), source location, parent
  (with select action), public URL (or its explicit unknown state), and
  role separate. Incoming/outgoing dependency lists with kind badges;
  source-only includes display as source files with a "Source file — not
  a page" note. Per-page problems with severity, code, location, and
  origin.
- `SourcePreview.tsx` — read-only raw source view via
  `client.getSource()` for the selected page while the graph is current
  (stale graphs refuse the preview and say why). Shows original line
  endings and the file hash prefix. Failures render as error text.
- `StatusBadge.tsx` — status mapping; unset is an explicit "Unset" badge.

Read-only is explicit in the page copy: selection and filters never save
or modify anything.

## Spec conflicts or notable decisions

- The Astryx `TreeList` names its accessible tree from the `header` prop
  (`aria-labelledby` wins over `aria-label`); the outline tree is
  announced as "Outline".
- The `<pre>` source region is keyboard-focusable (WCAG scrolling-area
  focus) with `role="region"`; the eslint `no-noninteractive-tabindex`
  rule was configured to allow that exact pattern.
- Auto-selecting the first root on load makes the inspector demonstrate
  itself; the selection remains inspection-only.
